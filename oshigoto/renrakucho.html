週案を直すと、連絡帳（Googleスプレッドシート）の時間割・宿題・決まった持ち物も自動で直ります。

はじめに1回：連絡帳にプログラムを入れる

1プログラムをコピーする

2連絡帳に貼る

  1. 連絡帳を開き、上のメニューの「拡張機能」→「Apps Script」を押す（新しいタブが開く）
  2. 真ん中の function myFunction() { } をクリックし、Ctrl + A → Delete で消す
  3. Ctrl + V で貼り、上の 💾（保存）を押す

3動かして許可する

  1. Apps Script の画面の上で、「▶ 実行」の右の欄を「onOpen」にして「▶ 実行」を押す
  2. 「承認が必要です」と出たら「権限を確認」→ 自分のアカウント →（「確認されていません」と出たら「詳細」→「移動」）→「許可」
  3. 連絡帳のタブにもどると、上のメニューに「連絡帳」が出ます

4週案をつなぐ

  1. 連絡帳のメニュー「連絡帳」→「はじめに：週案をつなぐ」
  2. 週案のリンク（週案を開いたときの上のアドレス）を貼って「OK」
  3. もう一度「許可」を聞かれたら、3と同じように許可する（週案を読むため・自動で動かすため）
  4. 「設定」の画面が出るので、自分の学年のふだんの時間数・下校時刻・持ち物を入れて「保存する」（はじめは5年生の決まりが入っています）

これで終わりです。週案にある今週から先の週のタブができて、時間割・宿題・持ち物が入ります。週案はプログラムが読むだけで、書きかえません。

しくみと決まり

A週のタブを作る

  • 自動で：週案に新しい週のタブができると、連絡帳にも同じ週のタブが自動でできます（週案に足したタブは、すぐに。週案のメニュー「週のタブを作る」で作ったタブは、10分以内に。「原本」のタブをもとに作ります）
  • 週を選んで：連絡帳のメニューから期間を選んで、まとめて作ることもできます（足りない週があるときなど）

休みの日：週案でグレーの日と祝日は、先生の形（「時」のところに「敬老の日」などの名前、ほかの行は空）にします。グレーで祝日でない日は、週案に書いた行事（「振替休業日」など）、なければ「休み」。前の日の「時」には「（月曜は休み）」と書きます。

連絡帳にもうある週は作りません。週を選ぶときは、メニュー「連絡帳」→「週を選んでタブを作る」。

B自動で書くもの・先生が書くもの

時次の日の時間割。週案で変わったところだけ（例：火曜　①体育　それ以外通り）と、早く帰る日の下校時刻
し週案の「宿題」の行
持決まった持ち物（月曜セット・体そう服など）。絵の具セットなどは先生が書く
連先生が書く（週案に書く行がないため）

連絡帳の「5-1」「5-2」（3クラスなら「5-3」も）の列に、週案の1組・2組・3組から書きます。週案と連絡帳は、5年生の形をコピーして使ってください。

C下校時刻（学年ごとに設定）

メニュー「連絡帳」→「設定（時間数・下校時刻・持ち物）」で、いつでも直せます。はじめは5年生の決まりです：

3時間目まで11時35分下校
4時間目まで＋給食13時15分下校
5時間目まで14時20分下校

いつもより早く帰る日だけ書きます（月・火・木・金はふつう6時間、水はふつう5時間）。

Dいちばん新しく直したほうが残る

  • 連絡帳で手で直したところは、そのまま残ります
  • そのあと週案のその日を直すと、連絡帳もその日のところだけ週案の内容になります
  • 週案を直すと、ふつうは数秒で連絡帳に出ます（おそくても10分以内）
  • 過ぎた日（もう配った日）は書きかえません

E連絡帳のメニュー「週案から自動入力」

ふだんは押さなくても自動で直ります。全部を週案に合わせたいときだけ押します。押すと注意が出ます。

連絡帳で直接手入力した内容が、週案の内容にもどります。よろしいですか？
