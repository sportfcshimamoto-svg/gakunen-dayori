トップ週案自動入力連絡帳自動入力学年だより作成授業時数算出シート自動入力

週案（Googleスプレッドシート）に「週案 → 週のタブを作る」のメニューを入れます。入れるのは1回だけ。そのあとは週案の中だけでタブが作れます。

1プログラムをコピーする

2週案に貼る

  1. 週案を開き、上のメニューの「拡張機能」→「Apps Script」を押す（新しいタブが開く）
  2. 真ん中の function myFunction() { } をクリックし、Ctrl + A → Delete で消す
  3. Ctrl + V で貼り、上の 💾（保存）を押す

3はじめの1回だけ、動かして許可する

  1. Apps Script の画面の上で、「▶ 実行」の右の欄を「onOpen」にして「▶ 実行」を押す
  2. 「承認が必要です」と出たら「権限を確認」→ 自分のアカウント →（「確認されていません」と出たら「詳細」→「移動」）→「許可」
  3. 週案のタブにもどると、上のメニューに「週案」が出ます

「承認」のところで止められて進めないときは、学校のアカウントでは使えません。

4使う

週案のメニュー「週案」→「週のタブを作る」。右に出るパネルで、① 組ごとに時間割を貼る（2クラスでも3クラスでも） ② 期間を選ぶ →「週のタブを作る」。

前の週案から移す（形のちがう週案を移すとき）

形のちがう週案（1年生の週案など）を、この形の週案に移せます。前の週案は読むだけで、変えません。

  1. 5年生の週案で「ファイル」→「コピーを作成」。コピーの週のタブ（「825」「1月11日」など）を消す（Shift を押しながらタブを選ぶと、まとめて消せます）。「原本2」「A週」などのひな形は残す
  2. コピーに、上の 1〜3 でプログラムを入れる
  3. メニュー「週案」→「前の週案から移す」。前の週案のURLを貼って「読み込む」→ 移す週を選んで「移す」

移すもの：日付・朝学・1〜6校時（教科と、その下のマス）・宿題。色は休みのグレーだけ（黄色などの色はうつさず、「分割」も入れません）。「児童・教員・日程」の行など、この形にない行は移しません。はじめて使うときは、もう一度「許可」が出ます（前の週案を読むため）。
